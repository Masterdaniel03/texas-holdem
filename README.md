# Texas Hold'em Poker Solver

A Python poker solver that calculates optimal betting decisions using Game Theory and Monte Carlo simulations.

## What It Does
- Simulates Heads-Up Texas Hold'em game states.
- Implements **Counterfactual Regret Minimization (CFR)** to learn optimal play.
- Uses **Monte Carlo Tree Search (MCTS)** to evaluate hand equities.
- Speeds up matrix updates using **NumPy**.

## How to Run
```bash
python main.py
